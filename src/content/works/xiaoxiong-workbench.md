## 这是什么

一个完全为自己服务的自媒体与个人 OPC（一人公司）工作台。做自媒体的人都知道，选题散在备忘录、客户需求散在微信、发布记录散在各平台后台——这个工作台把这些全部收进一个本地优先的 Web 应用，界面按苹果式简约标准来做，电脑为主、手机适配。

## 能做什么

- **今日**：待办、重要事项、发布日历、客户跟进和快速灵感记录。
- **随手记**：灵感、语录、笔记、链接、录音，支持原声回放和上传录音文件。
- **内容工作室**：选题 → 脚本 → 制作 → 待发布 → 已发布，全流程阶段管理，关联随记和资料，保存原始文件。
- **八平台版本**：抖音、小红书、快手、视频号、朋友圈、公众号、X、微博的文案、排期和手动发布记录。
- **作品归档包**：一键下载 ZIP，包含作品、平台文案、关联资料和原文件。
- **资料馆**：链接、文档、图片、视频、音频，类型筛选、标签和搜索。
- **客户与业务**：客户跟进、服务说明、报价方案、交付清单，关联生成跟进待办。
- **全局能力**：Ctrl+K 全局搜索、完整 ZIP 备份与恢复校验、日历 ICS 导出、桌面通知。

## 技术要点

- 后端只用 Python 标准库起本地 HTTP 服务，**零第三方运行时依赖**，日用不需要装任何包。
- 前端为原生实现，按手机尺寸逐页验收；支持局域网「手机访问模式」：扫码绑定、访问令牌、数据实时同步。
- 数据全部落在本地 SQLite（`bear.db`）+ 附件目录；自带完整备份下载和**可校验的恢复工具**（核对数据库完整性、附件清单及文件大小）。
- UI 验收使用 Playwright + 独立浏览器实例跑真实流程，验收记录落在 `docs/验收记录.md`。

## 边界（刻意的）

不自动登录、不自动发布、不私信、不操作账号——所有平台动作都由人手动完成，工作台负责把「人要做的动作」组织到最顺。数据只在自己电脑上，不做公网暴露。
